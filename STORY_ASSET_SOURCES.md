# Story asset sources

Generated portrait adaptations and cottage backgrounds prepared September 12, 2026 using image generation from user-provided references.

- Boy reference: user Pixilart screenshot codex-clipboard-21699333-037b-4f03-a072-3d6d986d768b.png. User identified Valorant's Iso as inspiration. Only the male sprite was used.
- Mother reference: RPG-Fantasy-Girls-IV V3.0 / Ember-Kazoku / Ember-Human3_D.png.
- Witch reference: [FG-Generator][SFW] Annabel-Mage / Human Body.png, Dress.png, Magic Hat (Human).png. Adapted to an elder character for the story.
- Original mother/witch pack licences were not established in this task; keep their original usage terms with the project when available.
- Panel: existing Dark Ages UI by Hypnobius; licence remains in assets/third_party/DarkAgesUi_v1.0/LICENSE.txt.
- Cinzel: https://github.com/google/fonts/tree/main/ofl/cinzel
- IM Fell English: https://github.com/google/fonts/tree/main/ofl/imfellenglish
- Font licences included in assets/fonts/story.

Generated portraits use a green RGB backing; portrait_chroma.gdshader removes it at runtime. No original reference files or gameplay sprites were overwritten.
